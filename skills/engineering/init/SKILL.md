# Init AGENTS.md

AGENTS.md 是**入口地图，不是完整文档**：只放每次会话都需要的高信号信息，其余通过指针按需深入。

## 硬性约束

- **≤ 60 行**。
- 单节超过 8 行时，把细节下沉到子文档，本节只留指针。
- 目录树只做**带行内注释的紧凑树**：顶层目录 + 源码根下 1–2 层关键子目录，跳过 `node_modules`/`dist`/`build` 等生成目录；更深或非关键路径让 agent 自己读。
- 已有上下文文件（`.cursorrules`、`CLAUDE.md`、`README.md` 等）直接链接，不复述。

## 步骤

### 1. 发现与盘点

若 `AGENTS.md` 已存在，先通读，保留人工撰写的上下文。然后浏览仓库，覆盖：

- **技术栈**：语言、框架、构建工具及版本。
- **工作流**：安装、测试、构建、启动命令。
- **结构**：源码根、测试目录、关键文档。
- **约定**：格式化/lint 工具、架构模式、编码风格。

### 2. 生成

信息较多时用「一句话摘要 + 指针」模式，细节沉淀到 `docs/agents/` 或既有文档：

```markdown
- 架构分层与数据流：见 [docs/architecture.md](docs/architecture.md)
- 提交与分支规范：见 [CONTRIBUTING.md](CONTRIBUTING.md)
- 后端约定：见 [services/api/AGENTS.md](services/api/AGENTS.md)
```

按模板生成。章节顺序保持，无内容的章节直接删除：

```markdown
# {PROJECT_NAME}

> 一句话说明项目做什么

## 技术栈

- 语言/框架/构建工具及版本

## 常用命令

- 安装：`{CMD}`
- 测试：`{CMD}`
- 构建：`{CMD}`
- 运行：`{CMD}`

## 目录结构

{TREE_VIEW}

## 编码规范

- 风格/lint/格式化工具及关键规则（≤3 条）
- 架构模式一句话 + 指针

## 上下文指针

- 深入某主题时优先阅读的文档链接（按需增减）

## 注意事项

- 关键陷阱或特殊上下文（≤3 条，每条一行）
```

目录树示例：

```text
├── src/             # 源代码
│   ├── common/      # 通用工具和算法
│   ├── service/     # 数据服务 API
│   └── index.ts     # 入口文件
├── examples/        # 示例代码
└── package.json     # 项目配置
```

### 3. 校验

- [ ] 行数 ≤ 60（超限则继续下沉到子文档）。
- [ ] 每节有实质内容，无空标题。
- [ ] 已有上下文文件以链接方式纳入，未复述。
